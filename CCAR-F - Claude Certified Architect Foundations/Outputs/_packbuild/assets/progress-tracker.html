Your Progress Tracker

Paste the results JSON from each practice paper and this page keeps your running record — score, scaled estimate, per-domain accuracy and how you are trending. Everything is stored in this browser only. Nothing is uploaded anywhere.

Add a result

Finish a paper, click Copy results JSON on its results screen, and paste it here. Add each paper as you complete it — earlier entries are kept, and re-pasting the same paper updates it rather than duplicating.

Scaled score is round((correct / 60) × 900 + 100) against a pass line of 720 — a linear approximation, not the psychometric scaling the real exam uses. Treat it as a rough gauge. Your data lives in this browser's local storage under ccaf-pack-progress; clearing site data or using a different browser will empty it, so use Copy all my results if you want a backup.
