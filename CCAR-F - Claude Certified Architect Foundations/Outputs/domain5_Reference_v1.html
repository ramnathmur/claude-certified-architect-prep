TS 5.1

Context Preservation

Summarisation is lossy compression that disproportionately destroys high-value tokens.

What Summarisation Compresses Away First

  • Numerical values: "$247.83 refund" → "a refund"
  • Dates: "March 3rd" → "recently"
  • Order/case IDs: "#8891" → omitted entirely
  • Percentages / quantities: "32% increase" → "an increase"
  • Customer-stated expectations: "by Friday" → vanished

The Fix: Persistent "Case Facts" Block

Extract transactional facts into a structured block. Inject verbatim into every prompt. Summarisation never touches it.

Lost in the Middle: Structural Attention Bias

Transformer attention is empirically biased toward the beginning and end of long inputs. Information buried in the middle is measurably less likely to be retrieved correctly.

Mitigation Strategies

  • Place key findings summaries at the beginning
  • Use explicit section headers to aid navigation
  • Surface relevant slice of long tool results at the top, full payload below
TS 5.2

Escalation and Ambiguity Resolution

Three valid escalation triggers. Two superficially plausible triggers do not work.

Valid escalation triggers
TriggerRequired Action
Customer explicitly requests a humanEscalate immediately. Do not attempt resolution first.
Policy exception or gap (request outside documented policy)Escalate — the agent cannot invent policy
Inability to make meaningful progressEscalate after legitimate avenues tried
Two unreliable triggers (wrong answers): Sentiment-based (customer is frustrated) and Self-reported model confidence.

The Frustration Nuance (Heavily Tested)

  • Straightforward issue + frustrated customer (no human request): Acknowledge frustration, offer resolution, do not escalate yet
  • Customer reiterates preference for a human after you offer help: Now escalate
  • Customer explicitly says "I want a human" up front: Escalate immediately
TS 5.3

Error Propagation

How a failure is reported matters as much as that it happened.

Structured Error Context: Four Required Fields

  1. Failure type: transient / validation / business / permission
  2. What was attempted: Specific query, parameters, endpoint, request shape
  3. Partial results: Anything gathered before the failure
  4. Potential alternatives: Suggested retry, fallback path, narrower query

The Two Anti-Patterns

  • Silent suppression: Return empty array on tool failure → Orchestrator believes no data exists. ZERO recovery path. Worst answer in any 5.3 question.
  • Workflow termination: Kill the entire pipeline on a single tool failure → Throws away partial results from other subagents that succeeded

Access Failure vs Valid Empty Result (Exam Favourite)

TypeMeaningCorrect Response
Access failureTool could not reach the data sourceConsider retry or alternative path
Valid empty resultTool reached source, found no matchesNo retry. The empty result is the answer.
TS 5.4

Codebase Exploration

Extended agentic sessions degrade when verbose discovery output dilutes early findings.

Two Symptoms of Context Degradation

  1. Model references "typical patterns" instead of session-specific facts
  2. Context fills with verbose discovery output and earlier conclusions get buried

Four Mitigation Strategies

  • Scratchpad files: Write key findings to a file, reference for subsequent questions
  • Subagent delegation: Spawn a subagent for specific investigation; coordinator receives distilled result only
  • Summary injection: Summarise findings from one phase before spawning next-phase's subagents
  • /compact: Reduce context usage when verbose output fills the window

Crash Recovery: Manifest Pattern

Each agent exports structured state to a known file location (a manifest) at meaningful checkpoints. On resume, the coordinator loads the manifest and injects it into the resumed agent's prompts.

The manifest is the source of truth, not the conversation history. Robust to process crashes, context window exhaustion, operator interruptions, and long-running jobs spanning multiple sessions.

TS 5.5

Human Review and Confidence Calibration

Calibration requires ground truth, not intuition. Aggregate metrics hide stratum-level failures.

The Aggregate Metrics Trap (Exam Favourite)

"Our extraction system achieves 97% accuracy. We can automate."

The trap: 97% overall accuracy can hide a 40% error rate on a specific document type. If that type is high-value, your automation is dangerous.

Discipline: Always validate accuracy by document type and by field segment before automating.

Stratified Random Sampling: Ongoing Audit

Even after calibration and deployment, continue sampling high-confidence extractions for ongoing verification. Novel error patterns emerge over time; failures slip through silently if not sampled.

Field-Level Confidence Calibration: The Full Pattern

  1. Per-field confidence (not per-document) — Fields within a document vary wildly
  2. Calibrate thresholds on a labelled validation set — Ground truth. Raw "0.85" might mean 70% correct or 95% correct depending on context
  3. Route low-confidence fields to human review — The rest auto-process
  4. Prioritise scarce reviewer capacity on highest-uncertainty items
TS 5.6

Information Provenance

Attribution must travel with every claim as structured data. Conflicts are surfaced, not resolved.

Structured Claim-Source Mappings: Five Required Fields

  • Claim: The assertion itself
  • Source URL: Direct link
  • Document name: Human-readable identifier
  • Relevant excerpt: The actual passage supporting the claim
  • Publication date: Temporal context

This bundle travels with the claim through every downstream agent. Without this structure, attribution dies the moment any agent summarises.

Conflict Handling

Wrong: Arbitrarily pick one. Average the values. Pick the more recent silently.

Right: Annotate with both values and full source attribution. Let the consumer decide.

Temporal Awareness

Many apparent contradictions are actually different reporting periods. A 28% figure from 2022 and a 32% figure from 2024 show change over time, not conflict.

Quick Reference

One-Line Mnemonics

  • Summarisation compresses numbers, dates, IDs first. Extract into a persistent block that summarisation never touches.
  • Lost in the middle is structural. Put summaries at the beginning, use section headers.
  • Three valid escalation triggers: explicit human request, policy gap, no meaningful progress.
  • Two unreliable triggers: sentiment, self-reported confidence.
  • Explicit "I want a human" = escalate now, do not investigate.
  • Frustration alone = offer help first; escalate if reiterated.
  • Structured error = type + attempt + partial results + alternatives.
  • Silent suppression is the worst pattern. Empty results with status=ok = no recovery path.
  • Access failure ≠ valid empty. Retry only the former.
  • Long sessions degrade: scratchpad, subagents, summary injection, /compact.
  • Manifest files are the source of truth across crashes. Not conversation history.
  • 97% accuracy can hide 40% on a stratum. Validate by document type AND field segment.
  • Per-field confidence, calibrated on ground truth. Raw 0.9 means nothing without it.
  • Every finding carries: claim + URL + doc + excerpt + date. Attribution dies otherwise.
  • Surface conflicts with both values and attribution. Never average. Never silently pick.
