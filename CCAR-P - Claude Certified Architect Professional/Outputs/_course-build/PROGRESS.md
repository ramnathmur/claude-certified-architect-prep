## How to build and check

- `node extract-data.js` re-reads the guide PDF, Objective Map and Facet Ledger into `data/` (run only if the sources change).
- `node build.js` assembles `src/head.html` + `fragments/*.html` + `src/foot.html` into the output and runs `gates.js`. With `COURSE_OUT=<file>` it builds to a private file; with `GATE_PAGES=<id>` it checks only that page.
- `gates.js` checks: anchor (38 objectives and 7 weights vs the PDF), unique ids, internal links, tag balance, coverage (every section and facet of a written chapter), structure, voice lint, arithmetic (`data-calc`), token contrast.
- Browser checks run by hand over localhost: `python -m http.server 18792 --directory "<CCAR-P>\Outputs"` in a terminal tab, then `http://localhost:18792/CCAR-P_Syllabus-Course_v1.html`. Paste `tools/browser-sweep.js` into the Chrome javascript tool (SVG overflow/overlap, SVG text contrast in both themes, horizontal overflow); check 390 px through an iframe and `window.__course.show(id)`; try search, index, plan, keyboard. Clear the `ccarp-course:v1` localStorage key afterwards.

## Fragment contract (one file per page in `fragments/`)

- Objective chapter `o<d>.<n>.html`: `.chapter` > `.main` (prose, `section.concept#c<sec>[data-src]` per corpus section, rules list with `data-facet`, figures, `details.deeper`, `section.bites`, `details.say`, `nav.xlinks`, `p.src`) + `aside.remember` (3 to 6 rules). Full contract in `AUTHORING.md`.
- Page header and title block are generated from `data/guide-objectives.json`, never typed.
- Terms are defined once with `<dfn data-def="...">`; computed numbers carry `data-calc` and `data-expect`.

## Build traps found

- `pdftotext -layout` output is Latin-1 and its bullets are 0xB7; the Read tool's PDF mode needs pdftoppm and fails here.
- Heredocs that pass backslash sequences through Python or node into JS source corrupted a regex (a literal carriage return). Edit files with the Edit tool.
- The Chrome tool cannot resize the window; test narrow widths with a 390 px iframe and `window.__course.show(id)` inside it.
- A figure on a 616-unit viewBox needs a `.scroll` wrapper and `min-width: 560px` or its text shrinks below legibility on phones.
- Forks inherit the whole conversation: three died on 2026-10-25 (stall, "Prompt is too long", session limit). Use fresh agents with the brief above.
- Two headless `claude -p` reviewers started together collided and one produced nothing: run them one at a time.
