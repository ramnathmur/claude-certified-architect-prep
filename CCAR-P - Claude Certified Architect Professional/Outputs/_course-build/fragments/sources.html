  4. Anthropic's live documentation and engineering posts, checked for any product fact a chapter adds beyond the corpus. Checks made: "Introducing Contextual Retrieval" (read 2026-10-24); the model overview, prompting guidance, extended thinking, prompt caching, context windows and Agent Skills pages (2026-10-25); "Building effective agents", the multi-agent research post, and the Agent SDK subagent and agent-loop pages (2026-10-25); the tool definition, tool search, MCP architecture and Claude Code MCP pages (2026-10-26); and the Claude Code memory, skills, hooks and CLI pages (2026-10-27).
