Domain 7 carries 7% of the exam, about 4 of the 63 items, across three objectives. It is the smallest domain, and it is also the one with the most product detail: where Claude Code reads its configuration, which settings win, and which mechanism can enforce a rule.

The items turn on one distinction. An instruction shapes what Claude tries to do, and a setting changes what Claude Code allows. Most wrong answers fix a configuration problem with more prose. The table below is the course's reading of the domain, not the guide's wording.
