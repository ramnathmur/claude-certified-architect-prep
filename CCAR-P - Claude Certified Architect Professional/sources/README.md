## Naming

`CCAR-P_Official-Exam-Guide_v<version>.pdf` — use the version printed in the document, not a
sequence number of your own. If the document carries no version, use its date:
`CCAR-P_Official-Exam-Guide_2026-08.pdf`.

Never overwrite a previous version. The Foundations guide moved from v0.1 to v1.0 and dropped a
whole section; having both files is what made that diff visible.

## When a guide lands

update `../EXAM-FACTS_v1.md`. Nothing else in the project is trustworthy until that is done.
