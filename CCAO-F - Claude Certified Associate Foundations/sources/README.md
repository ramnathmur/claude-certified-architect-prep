## Naming

`CCAO-F_Official-Exam-Guide_v<version>.pdf` — use the version printed in the document, not a sequence
number of your own. If the document carries no version, use its date:
`CCAO-F_Official-Exam-Guide_2026-08.pdf`.

Never overwrite a previous version. The CCAR-F guide moved from v0.1 to v1.0 and dropped a whole
section; having both files is what made that diff visible.

## When a guide lands

Run the Phase 0 reconciliation checklist in `../prep with quiz/CCAO-F_Corpus-Index_v1.md`, then update
`../EXAM-FACTS_v1.md`. Nothing else in the project is trustworthy until that is done.

The single most valuable thing this guide settles for CCAO-F is whether items are standalone or come
in scenario blocks. CCAR-F drew 4 blocks of 15 items from a pool of 6, and that structure dictated how
every mock paper had to be built. The community source for CCAO-F describes standalone items and does
not mention blocks at all — one of those two pictures is wrong.
