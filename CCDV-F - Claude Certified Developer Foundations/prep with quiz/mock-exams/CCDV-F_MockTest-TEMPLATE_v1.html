CCDV-F Mock Exam Template

This file is the CCDV-F mock-exam engine, not a paper. It ships with the three sample questions published in the official exam guide (Section 8) so the engine can be exercised end to end - they are illustrative items Anthropic states are not drawn from the live item bank. A real paper replaces the item array wholesale with 53 items generated from the eight CCDV-F domain corpus files. See README.md in this folder.

Multiple-response items
Every item states its own response count in the stem - that is how the real exam is specified, so the count is the first thing to read. Multiple-response items here are scored all-or-nothing: a majority-right answer scores zero. That is an assumption, not a published fact - the guide does not say. Eight CCAR-F misses came from exactly this leak.
Exam mode
No per-question feedback, no live score, no correctness colour. Answers stay freely changeable until you submit - click again, use Back, or jump from the map. The timer counts 120:00 down and floors at 0:00 without auto-submitting; this is a practice tool, not proctoring software.
